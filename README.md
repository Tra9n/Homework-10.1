# Homework-10.1

## Описание:

Проект Homework-10.1 - это приложение на Python для управления задачами и проектами.

## Установка:

1. Клонируйте репозиторий:
```
git clone git@github.com:Tra9n/Homework-10.1.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:

1. Откройте приложение через Pycharm.
2. Клонируйте репозиторий с github.
3. Используйте processing.py для нужных вам задач.
