# Проект по тестированию функций на Python

## Описание

Этот проект содержит модули и тесты для функций, связанных с обработкой данных банковских карт и счетов. Основная цель — продемонстрировать навыки тестирования с использованием библиотеки pytest.


## Структура проекта


		• src/: содержит исходный код проекта.


masks.py: функции для маскирования номеров карт и счетов.

processing.py: функции для фильтрации и сортировки данных.

widget.py: функции для обработки и преобразования данных.



		• tests/: содержит тесты для модулей проекта.


test_masks.py: тесты для функций из masks.py.

test_processing.py: тесты для функций из processing.py.

test_widget.py: тесты для функций из widget.py.




## Установка и запуск тестов


		1. Клонируйте репозиторий:

git clone <URL репозитория>


		2. Установите необходимые зависимости:

pip install -r requirements.txt


		3. Запустите тесты:

pytest
